## ✨ About The Project

Welcome to the **Pattern** repository! This project is a playground for algorithmic art. Using the simple yet powerful `turtle` graphics library in Python, we generate complex, beautiful, and sometimes trippy visual patterns ranging from fractal trees to mathematical hearts.

Whether you're here to learn about math-based art, recursion, or just want to watch some cool animations draw themselves on your screen—you've come to the right place.

## 🖼️ The Patterns

Click on any pattern below to reveal details and how to run it!

<details>
<summary><b>❤️ Mathematical Hearts (heart.py & heart2.py)</b></summary>
<br>
Watch the turtle draw a perfect heart shape using parametric equations! The scripts use `math.sin()` and `math.cos()` to precisely calculate the coordinates of a classic heart curve. 

```bash
python heart.py
```
*Tip: Try running `heart2.py` as well for different color variations!*
</details>

<details>
<summary><b>🌀 Geometric Mandala (pattern.py)</b></summary>
<br>
A colorful, rotating geometric mandala. It utilizes the `colorsys` module to smoothly transition through the HSV color space, creating a beautiful rainbow effect as it draws overlapping circles.

```bash
python pattern.py
```
</details>

<details>
<summary><b>🌳 Fractal Tree (pattern2.py)</b></summary>
<br>
A beautiful recursive fractal tree with orange leaves (circles) and brown branches. It perfectly demonstrates the power of recursion in Python!

```bash
python pattern2.py
```
</details>

<details>
<summary><b>🔮 Complex Geometries (proj1.py, proj2.py, sample.py)</b></summary>
<br>
Additional complex geometric designs, spirographs, and wild patterns. Run them to see what secret shapes they generate!

```bash
python sample.py
```

## 🚀 How to Run

It's super easy! The `turtle` module is built into standard Python, so no extra installations are required.

1. **Clone the repository** (or download the files)
   ```sh
   git clone https://github.com/your-username/pattern.git
   cd pattern
   ```

2. **Run any script**
   ```sh
   python pattern.py
   ```
   *(A new window will open and the drawing animation will begin automatically!)*
