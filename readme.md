# Python All Documents

Welcome to my Python learning repository! This repository contains a collection of Python scripts, categorized into different folders based on their purpose and learning stages.

## 📂 Directory Structure

### [Pattern](./Pattern/)
This directory contains scripts that print various patterns using Python loops.
- Heart shapes (`heart.py`, `heart2.py`)
- Different star/number patterns (`pattern.py`, `pattern2.py`, `sample.py`)

### [Python-Logic](./Python-Logic/)
Here you'll find common logical and mathematical problems implemented in Python.
- **Number checks:** Prime, Armstrong, Odd/Even, Leap year
- **Mathematical operations:** Factorial, Fibonacci, Square root, Area of a triangle
- **Other:** Logical exercises like string reversal and swapping variables.

### [python-chapterwise](./python-chapterwise/)
This section contains structured learning, chapter by chapter, covering basic to advanced concepts.
- `ch-1.py` to `ch-10.py`: Covering various Python basics.
- Object-Oriented Programming (OOP) concepts.
- Small projects (`proj.py`, `proj1.py`, `proj2.py`).

## 🚀 How to run
To run any of the scripts, you can use the `python` command from the root directory. For example:
```bash
python Python-Logic/fibbo.py
```
