## 📖 Overview

Welcome to the **Python Logic** repository! This is a beautifully curated interactive collection of foundational Python scripts focusing on core programming concepts, mathematical algorithms, and logical problem-solving. It's the perfect reference for brushing up on your Python fundamentals or exploring how classic algorithms are implemented.

## 🚀 How to Run

You can run any of these scripts directly from your terminal or command prompt. Make sure you have [Python](https://www.python.org/downloads/) installed.

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone https://github.com/Aniketsingh-45/Python-Logic.git
   cd Python-Logic
   ```

2. **Execute a script**:
   ```bash
   python armstrong.py
   ```
   *(Replace `armstrong.py` with the script you want to run!)*
